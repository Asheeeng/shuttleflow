# 校园摆渡车AI智能调度系统 — 使用说明

## 一、环境准备（只需安装一次）

### 1. 安装Java 8+
- 下载：https://aws.amazon.com/corretto/ （选JDK 8）
- 安装后验证：打开cmd输入 `java -version`，看到版本号即可

### 2. 安装MySQL 8.0
- 下载：https://dev.mysql.com/downloads/installer/
- 安装时设置root密码为 `Root@123456`（必须一致）
- 安装后验证：打开cmd输入 `mysql -u root -p"Root@123456" -e "SELECT 1"`，看到结果即可

## 二、每次使用步骤

### 步骤1：启动MySQL
MySQL安装后通常已开机自启，跳过即可。如未启动：
```
net start MySQL80
```

### 步骤2：初始化数据库（首次使用或想重置数据时执行）
```
mysql -u root -p"Root@123456" < init.sql
```
只需执行一次。后续启动跳过此步。

### 步骤3：启动系统
```
java -jar shuttle-1.0.0.jar
```
看到 `Started ShuttleApplication` 即启动成功。

### 步骤4：打开浏览器访问
```
入口页    http://localhost:8080/index.html
乘客端    http://localhost:8080/passenger.html
司机端    http://localhost:8080/driver.html
管理端    http://localhost:8080/admin.html
仿真台    http://localhost:8080/simulation.html
```

### 关闭系统
在运行jar的命令行窗口按 `Ctrl + C` 即可。

## 四、数据库密码不同怎么办

如果MySQL的root密码不是 `Root@123456`，用文本编辑器打开 `application.yml`，
修改第7行的 `password: 你的密码`，然后放在jar同目录下启动即可。

## 五、可选：启动AI服务（增强智能调度）

如需OR-Tools整数规划求解、CUSUM突变检测等AI增强功能：
```
pip install fastapi uvicorn numpy requests pydantic ortools
python main.py
```
不启动AI服务也不影响核心功能，系统会自动降级为内嵌规则调度。
