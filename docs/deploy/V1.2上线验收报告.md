# ShuttleFlow V1.2 上线验收报告

日期：2026-11-16　分支：`codex/v1.2-hardening-passenger-auth`　基线：`8b2c0ba`

## 结果

本分支通过当前环境中的构建、既有业务回归、安全集成及并发验收。没有连接或修改正式 VPS，也没有改动组内数据库；测试数据写入单独创建的 `shuttle_v12_fresh_768ae4` 和 `shuttle_v11_upgrade_768ae4` 两个本机隔离库。

## 已修复

- Fastjson 升至 1.2.84；新增兼容性测试。Java 编译目标仍为 8，Spring Boot 仍为 2.7.18。
- 管理员和司机口令以 PBKDF2-HMAC-SHA256 验证与保存；旧版管理员、司机明文口令在启动迁移中哈希并清空。登录响应不返回口令字段。新增乘客手机号注册与登录。
- 关闭公开司机注册；司机账号及车辆绑定由管理员创建。区分管理员与调度员权限，司机只能操作绑定车辆。管理和司机接口在服务端执行角色校验。
- 写接口加入限流和 CSRF 校验；游客签到具备会话幂等和取消归属校验，重复签到不重复增加队列，重复取消返回冲突且不重复扣减。
- 司机上下客、人数校准和容量更新加事务、车辆行锁和容量边界检查；队列变化使用原子数据库增量更新。
- 调度任务增加 UUID 编号、合法状态转换和并发保护；重复自动派单去重。WebSocket 按角色和车辆/线路范围发送事件。
- AI 内部调用要求服务令牌，AI 服务及应用默认绑定回环地址。数据库口令、服务令牌和引导管理员口令改由环境变量提供；应用账号不使用 MySQL root。
- 加入 Debian 12 单机部署材料：环境模板、systemd、Nginx HTTPS/WSS、MySQL/Redis 设置、备份恢复、健康检查、日志轮转、资源监控、更新及回滚脚本。Vue 3.5.45 与许可证已本地化。
- `release/shuttle-1.0.0.jar` 已用本分支当前源码重建，避免继续分发旧认证逻辑和易受影响依赖的历史二进制。

## 待处理与未验证

- 压测主机为 macOS 15.5 arm64、8逻辑CPU、16 GB RAM，数据库为 MySQL 8.4.11。结果不是 Debian 12、4 vCPU、4 GB RAM 或 MySQL 8.0 目标机的实测数据；目标机的安装、恢复、资源限额和压力表现仍需部署后验收。
- 未连接正式 VPS。公开过的历史演示账号、root 口令及服务令牌应按已泄露处理；上线前须依部署手册轮换，并启用 HTTPS、Secure Cookie 和 Redis 认证。TLS 证书、云安全组和正式备份恢复尚未在目标服务器实测。
- 本机使用的 Redis 服务没有配置 `maxmemory`；生产配置已给出256 MB上限及事件流长度控制，需在目标环境确认生效。
