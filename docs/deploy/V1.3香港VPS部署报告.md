## 等待服务器交互式安装

SSH 账号的非交互 sudo 不可用。需由用户在可信的 Tabby 会话执行：

```bash
sudo bash /home/shuttle/vps-deploy/shuttle-v13-9c895db/deploy/v13/install.sh
```

脚本在隐藏提示分别接收应用管理员和 HTTPS 入口密码。两者须不同，且均需至少 20 位字母或数字。入口用户名是 `v13gate`，应用管理员用户名是 `v13admin`。

脚本先备份 V1.2 应用、数据库及 Nginx，再配置 V1.3 独立服务。目标地址为 `https://v13.shuttleflow-gzu.duckdns.org/login.html?role=admin&next=simulation.html`。证书签发、库与服务启动、备份、邮件告警送达、公网 API 验收及无头浏览器复验仍需实测。

安装脚本包含 100 名虚拟乘客和 4 辆车辆的公网 HTTPS/WSS API 验收，成功后写入 `/var/backups/shuttle-v13/public-acceptance.json`。实际浏览器回放与导出需要在安装之后用项目的 `public-ui.mjs` 验证。维护和回滚见 [独立部署手册](../../deploy/v13/README.md)。
