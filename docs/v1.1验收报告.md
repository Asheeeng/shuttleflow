## 登录、安全与数据

- 口令使用 Java 8 自带 PBKDF2-HMAC-SHA256、310,000 次迭代和逐口令随机盐；登录使用 HttpOnly 会话 Cookie、登录会话 ID 轮换及 CSRF 令牌。
- 管理与司机 API 由后端校验角色，司机操作还校验车辆绑定；调度员不能修改车辆运行状态。WebSocket 握手也要求有效会话。
- 乘客可游客访问；游客写请求必须带 CSRF 令牌，只能取消同一会话建立的候车请求。
- FastAPI 仅监听本机回环地址，业务 API 要求服务端令牌。令牌只放在 `.runtime/local.env` 与 `.runtime/ai.env`，不进入浏览器或 Git。
- 迁移前备份：`.runtime/shuttle-v11-before-auth.sql`。首次启动只追加 `password_hash` 列并转换旧演示口令；首次日志显示司机12条、管理账号2条，后续重复启动均为0条。没有执行初始化 SQL，3306 现有数据库未触碰。
- 原测试套件会在隔离的 3308 演示库产生事件和统计快照；未运行 DROP、删表或重置数据操作。

## 未覆盖项

- 本轮未做 Windows 主机上的实际启动验收；项目依然使用 Java、Python、MySQL 常规跨平台运行方式。
- Vue 继续由 unpkg CDN 提供，离线环境需后续将 Vue 资源本地化。
- 演示账号口令沿用当前 SQL 中的值，仅用于课程演示；公开部署前应轮换账号口令并使用 HTTPS。
