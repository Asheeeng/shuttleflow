## 分支与历史

- GitHub 原 `main` 为 `8b2c0ba`，备份分支为 `archive/v1.1-main-before-v1.3-midterm-2026-11-23`。
- 读取 GitCode 时只有默认分支 `master`，指向 `51f387e`。它与 GitHub 的组内原始导入 `36d23a1` 的应用、脚本和数据库文件相同，差异为忽略规则及 GitHub 侧新增的项目文档。发布提交接入原始 GitCode 提交，保留其祖先和原分支，功能文件保持 V1.3 基线。
- 发布分支为 `release/v1.3.0-midterm`。先验证发布分支，再把两个 `main` 更新到同一个发布提交。GitCode 首次建立 `main` 时保留既有默认 `master`。
- 原有 V1.2、V1.3 和 V0.2 分支以及 `v1.3.0` 标签保留。同步使用普通推送及快进。

核验两边 `main` 与标签指向：

```bash
git ls-remote origin refs/heads/main 'refs/tags/v1.3.0-midterm^{}'
git ls-remote gitcode refs/heads/main 'refs/tags/v1.3.0-midterm^{}'
```

四条记录的提交 SHA 应相同。两仓库主线验收后，后续改动先走发布分支和成员审查。
