# ShuttleFlow V1.3 仿真工作台 UI 验收

验收日期为 2026-11-18。使用 V1.3 独立分支和项目锁定的 Playwright Chromium，无头运行。

## 布局与组件

- 复用 `neo.css` 的 `--sf-*` 变量、`sf-mark`、`btn` 和 `sf-kpi-card`。运营样式负责分组、布局和图表形态，使用原有米白背景、黑边框、硬阴影和字体。
- 运营总览呈现模拟时钟、状态、KPI 和线路。仿真配置按场景与时钟、客流与调度、车辆编组分组。车辆运行包含原来已有的历史运行选择、逐站数据、回放及导出。预警、任务生命周期、策略对比和原算法演示各在对应标签。
- 运行和完成用绿色，开始用品牌黄，暂停用黄色提示，停止和故障用红色。状态含文字。初始加载、空数据、初始化、暂停、完成和故障均有对应视图。横向内容在图表及表格自己的区域内滚动。
- 管理员、司机和乘客的运营面板共用同一布局和组件。前端源码和 Java 发布用的静态目录保持一致。后端业务、接口和数据库结构未做本轮变更。
